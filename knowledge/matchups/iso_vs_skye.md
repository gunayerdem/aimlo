# MATCHUP: Iso vs Skye

## 1. Matchup Özü

Iso shield + kontingency wall + double tap ile 1v1 duelloları kazanmaya çalışan aim-focused duelist, Skye ise flash bird + trailblazer dog + heal ile takımına info sağlayan utility initiator. Matchup Iso'nun 1v1 shield ekonomisi ile Skye'ın bilgi + flash ağını test eder.

## 2. Kim Avantajlı?

**Iso lehine durumlar:**
- 1v1 izole duello alanlarında (Haven A Long, Lotus B Main) — Iso shield Skye'ın tek shot ihtimalini absorbs eder
- Skye utility harcanmış (bird + dog + flash kullanılmış) — Skye sıradan rifler, Iso aim duel'de avantajlı
- Iso ult hazır (Kill Contract) — ult Skye'ı izole dimensiyona çeker, Skye takım desteğinden mahrum
- Skye heal harcanmışken — takım HP reset edilmemiş, round ekonomisi Iso lehine

**Skye lehine durumlar:**
- Skye flash bird Iso'nun aim avantajını bozar — flash Iso'nun shield ekonomisine karşı ölçüsüz damage yaratır, blind Iso aim duel'i kaybeder
- Trailblazer dog Iso'yu stun'lar — dog range geniş, Iso shield stun'u absorbs etmez (shield damage için, CC için değil)
- Skye takım desteğinde — heal + info + flash, Iso solo duelist Skye'ın takım gücü karşısında bocalar
- Seekers ult durumunda — ult Iso'nun pozisyonunu zorla açar, nearsight + follow kesin kill fırsatı

**Balanced:** Bind, Split, Sunset gibi orta mesafeli map'lerde matchup Iso'nun shield timing'ine ve Skye'ın flash disiplinine bağlı.

## 3. Key Düellolar

**IF** Skye flash bird Iso'nun aim hattına kontrollü pop attı
**MEANING** Flash Iso'yu kör eder, shield flash'tan koruyamaz, Iso aim duel'de saldırganın aleyhine
**COUNTER** Iso flash sesini duyduğu an shield aktive, duvara dön. Flash sonrası shield hala aktif ise aim duel Iso lehine.
**WHY** Skye flash bird kontrol edilebilir trajektör, pop noktası Iso'nun crosshair hattında. Iso shield damage absorbs eder ama flash debuff'u absorbs etmez.

---

**IF** Skye trailblazer dog Iso'yu tag'ledi
**MEANING** Dog stun + damage, Iso shield CC'ye karşı etkisiz, Iso stun süresi boyunca aim'siz
**COUNTER** Iso dog sesini duyduğu an corner cover + rifle shot. Dog HP düşük, iki shot ile ölür.
**WHY** Dog CC + damage combo. Shield damage absorbs ama stun geçer. Dog'u rifle ile bitirmek matchup'ın teknik cevabı.

---

**IF** Iso shield aktif, Skye rifle shot ile ateş ediyor
**MEANING** Shield ilk shot'u absorbs eder, Iso karşı shot'u serbest — aim duel Iso lehine
**COUNTER** Skye shield'ı harcatmak için çoklu flash + team follow-up. Tek shot karşı shield boşa.
**WHY** Iso shield tek kullanım/cooldown. Shield'ı harcatmak takım gücü gerektirir, solo Skye shield'ı kıramaz.

---

**IF** Iso Kill Contract ultunu Skye'a attı
**MEANING** Ult 1v1 dimensiyonda Skye'ı izole, Skye takım utility'si olmadan Iso'nun aim duelunda
**COUNTER** Skye Kill Contract hattında durmasın, ult spawn lokasyonunu öngör. Takım arkadaşları Skye'ı ult öncesi cover alır.
**WHY** Ult Skye'ı takım gücünden koparır. 1v1 Iso aim duelunda shield + aim avantajlı.

---

**IF** Skye Seekers ultunu Iso'ya attı
**MEANING** Seeker Iso'nun pozisyonunu bulur, nearsight + slow debuff, Iso aim duel'e hazırlıksız
**COUNTER** Iso Seekers ses indicator duyduğu an corner cover + shield aktive. Seekers destroyable — aim ile seeker'ı bitirir.
**WHY** Seekers tracking ult. Iso aim'i seeker'ı yakalayabilir — seeker HP düşük, aim shot iptal eder.

---

**IF** Iso kontingency wall ile Skye'ın trailblazer hattını kesti
**MEANING** Iso wall projectile absorbs eder, trailblazer wall'ı aşamaz
**COUNTER** Skye trailblazer'ı wall yoksa gönder. Iso wall kullanım sayısı sınırlı, round'a göre.
**WHY** Iso wall tek yönlü projectile block. Trailblazer wall'da durur, Iso pozisyonunda güvenli.

---

**IF** Skye heal yaptığı sırada Iso peek aldı
**MEANING** Heal Skye'ı statik yapar, Iso aim duel'de bedava shot fırsatı
**COUNTER** Skye heal'i cover arkasında, görüş hattı dışında. Heal timing Iso'nun peek penceresiyle çakışmamalı.
**WHY** Heal statik pozisyon. Iso aim avantajı statik hedefe karşı maksimum.

## 4. Utility Takası

Iso utility'si solo (shield + wall + double tap + ult), Skye utility'si takım (flash + dog + heal + ult). Iso'nun kimliği 1v1, Skye'ın kimliği takım info. Matchup'ın özü Iso'nun 1v1 izolasyon sağlayıp sağlayamayacağı — izolasyon varsa Iso kazanır, Skye takım desteğinde ise Skye avantajlı. Ult ekonomisi: Kill Contract 7 point, Seekers 8 point — Iso ult daha ucuz, 1v1 izolasyon sağlar.

## 5. Map Bazlı Değişim

**Haven (Skye avantajlı):** Skye'ın 3 site info ekonomisi Haven'da maksimum. Iso niche pick.

**Lotus (Skye hafif avantajlı):** 3 site yapısı Skye utility'sine yarar.

**Bind (Iso hafif avantajlı):** Close range 1v1 duello Iso'nun shield ekonomisi.

**Split (Balanced):** Skye A Main info, Iso B Main close range.

**Ascent (Skye avantajlı):** Skye A Main entry meta, Iso Ascent'ta düşük pick.

**Icebox (Iso avantajlı):** 1v1 izole duello Mid Tube + Rafters Iso'nun.

**Sunset (Balanced):** Close range Iso, info + flash Skye.

## 6. Flip Moment'ler

**Flip 1 — Flash blind:** Iso flash'a yakalandıysa shield etkisiz, aim duel kaybı.

**Flip 2 — Dog stun:** Trailblazer Iso'yu stun'larsa shield koruma vermez, Iso savunmasız.

**Flip 3 — Shield aktif 1v1:** Iso shield aktif aim duel'de kesin kazanç.

**Flip 4 — Kill Contract izolasyonu:** Ult Skye'ı takımdan ayırırsa Iso aim avantajı maksimum.

## 7. Pro Coach Notları

**VCT'de nasıl oynanıyor:** Iso pro meta'da niche duelist, pick rate düşük ama artan trendde. Skye standard initiator, sık pick. Matchup pro seviyede Skye utility disiplinine bağlı — flash + dog kombosu Iso'nun shield ekonomisini yener, utility harcanmışsa Iso aim duel'e döner.

**Meta tier durumu:** Iso B+ tier, Skye A+ tier. Head-to-head Skye hafif avantajlı takım oyunu gücüyle.
