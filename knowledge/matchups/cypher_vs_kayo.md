# MATCHUP: Cypher vs KAY/O

## 1. Matchup Özü

Cypher tripwire + cage + cam + Neural Theft ile info ekonomisine bağlı sentinel; KAY/O suppress knife + Null Cmd ile bu ekonomiyi iptal eden anti-utility initiator. Matchup Cypher'ın setup'ı knife radius'u dışına taşıyıp taşıyamadığına bağlı — suppress zone içinde wire, cage, cam ve ult aynı anda çöker. KAY/O tarafında asıl soru knife'ı round başı entry için mi post-plant retake için mi harcadığı; ikisi birden olmuyor. Fight iki anti-utility silahın zamanlama düellosudur, aim ikincil.

## 2. Kim Avantajlı?

**Cypher lehine:**
- KAY/O knife round başı entry için harcanmış — post-plant retake tam ekonomi.
- Site anchor dar choke (Bind Hookah, Split B Main, Haven C Long) — wire hattında, flank radius dışı.
- KAY/O solo entry, trade kopuk — wire tag + aim kill alır.
- Map vertical (Icebox Mid, Split Vents, Lotus C Link) — knife yatay, vertical wire radius üstünde.
- Neural Theft dolu, KAY/O takımdan down — post-mortem reveal pozisyon açar.

**KAY/O lehine:**
- Suppress knife setup merkezine saplandı — wire + cam + cage + ult iptal.
- Setup pattern okunmuş — knife pre-aim tam radius.
- Flash peek hattında + entry senkron — aim duel kaybedilirse cam stun için zaman yok.
- Null Cmd aktif — takım-wide suppress, combat revive trade'i güçlendirir.
- Cypher takımında ikinci info agent yok — utility silindiğinde takım kör.

**Balanced:**
- Setup knife radius sınırında — round bazlı şans.
- Knife miss, duvar arkasına saplı — suppress yanlış zone'da, setup çalışır.
- Haven/Ascent 3 siteli rotation esnek; knife tek site'ta, diğer site dokunulmamış.

## 4. Utility Takası

Cypher ekonomisi wire ikili + cage ikili + cam + Neural Theft; KAY/O ekonomisi suppress knife + flash ikili + molly + Null Cmd. Matchup asimetrik — KAY/O'nun varoluş nedeni Cypher gibi utility-heavy agent'ları silmek. Burn-order Cypher için round başı setup (wire + cam), post-plant retake için wire yedek; KAY/O için knife ya round başı entry açmak için ya post-plant için harcanır, asla ikisi birden — cooldown round içi dönmüyor.

Cypher taktik avantajı variation: wire hattını iki round üst üste aynı noktaya kurmamak, cam lokasyonunu döndürmek, cage yönünü entry hattına göre değiştirmek. KAY/O knife açı kütüphanesi pro seviyede pre-learned — Bind Hookah'tan A Short, Haven C Long'dan Garage, Lotus A Tree'den A Main hatlarına sabit throw açıları mevcut. Cypher okuma yaparak setup'ı radius dışına taşıyabilirse knife ölü yatırım.

Re-info ekonomisi: Cypher suppress altında utility ile re-read yapamaz, takım info'suna bağımlı; KAY/O'nun flash ikilisi re-engage imkanı verir. Cypher'ın tek anti-suppress cevabı süreyi cover'da geçirip yeniden kurulum — round başı tüm wire'larını atmamalı, yarısını reserve tutmalı. Ult ekonomisi nominal eşit (Neural Theft 7 puan, Null Cmd 7 puan) ama impact asimetrik: Null Cmd Cypher'ın kimliğini ult süresince tamamen siler ve round-ending silahtır; Neural Theft KAY/O zaten öldükten sonra info verir, round içi impact yok, sonraki round için planlama. Cypher ult'u retake için, KAY/O ult'u execute veya post-plant locks için harcar.

## 5. Map Bazlı Değişim

**Bind (Cypher avantajlı):** Hookah'tan A Short hattına knife açısı pre-learned ama TP flank setup radius dışı. TP anchor role ile suppress'ten kaçar, wire TP çıkışında + cam Hookah — tek knife iki hattı birden kapatamaz. B Hall wire Bind'ın en güçlü post-plant hattı.

**Haven (dengeli, hafif Cypher):** 3 site knife ekonomisini tek site'a sıkıştırır — A'ya atılan knife C flank wire'ını etkilemez. Garage wire + C Long cam Haven meta, knife A Link veya C Link'ten ayrı sitelere denk gelir.

**Ascent (dengeli):** A Main uzun choke knife için ideal ama Catwalk flank wire + B Main cam meta setup tek hattı kapatır. Mid Cubby cam radius köşesinde, B Lane wire knife'ın atladığı nadir hatlardan.

**Lotus (dengeli):** 3 site + rotating doors esnek, knife tek door'a atıldığında diğeri açık. A Tree wire Lotus meta, A Main knife throw'u radius içinde — A'da KAY/O, B ve C'de Cypher.

**Split (KAY/O hafif avantajlı):** Dar vertical, suppress B Main + A Ramps choke'larında wire hattını tam kapsar. Vents flank wire Split'in tek kaçış noktası, açısı dışı. Site anchor wire'ları radius merkezinde, variation'a bağımlı.

**Sunset (Cypher hafif avantajlı):** A Main + B Market dar choke anchor meta, knife Market'e giremez — throw açısı dar. Mid Courtyard knife hattına açık, site anchor dominant.

**Icebox (Cypher avantajlı):** Uzun sightline + vertical katman KAY/O utility range'ini zorlar; Mid Orange + A Belt açı dışı, B Snowman + Kitchen vertical wire radius üstünde — topografik kaçış.

## 6. Flip Moment'ler

**Flip 1 — KAY/O knife'ı boşa harcadı:** Round başı knife entry için atıldı ama Cypher setup radius dışındaydı. Suppress boş zone'da, utility tam çalıştı. Cam ile KAY/O rotasyonu okundu, post-plant wire + cam retake hattını kilitledi. Knife cooldown dönene dek KAY/O kimliksiz fight etti, takım trade hattı çöktü. Flip Cypher lehine — KAY/O kimliğini round başı harcadı, geri kazanamadı ve Cypher round içinde dominant sentinel rolünü geri aldı.

**Flip 2 — Cypher setup pattern okundu:** Round 1-3'te wire A Short'a üst üste aynı yere kuruldu. Round 4'te knife pattern'e pre-aim attı, wire + cam merkezine saplandı. Suppress tüm setup'ı ult olmadan sildi, takım free entry yaptı. Re-setup için reserve yoktu. Flip KAY/O lehine — variation eksikliği pattern punishment.

**Flip 3 — Camera knife'ı stun'ladı:** KAY/O entry için throw etti, Cypher cam asimetrik yerdeydi. Trajektör cam sight'ından geçti, stun dart knife'ı havada tag'ledi, throw iptal. Suppress sıfır, setup tam çalıştı, wire tag aldığında entry utility + aim kayıp. Flip Cypher lehine — pro variation matchup'ı çevirir.

**Flip 4 — Null Cmd info ekonomisini sildi:** Round 6'da Null Cmd site execute hattında aktive edildi, takım-wide suppress wire + cam + cage'i iptal etti. Cypher cover'a çekilip ult süresini kimliksiz geçirdi, combat revive trade hattını güçlendirdi, plant tamamlandı. Ult sonrası wire ekonomisi round başı tükenmişti, retake açık kaldı, takım info üretemedi. Flip KAY/O lehine — Null Cmd matchup'ın direkt cevabı olmayan en büyük round-ending silahı, timing Cypher için tek kaçış yolu.

**Flip 5 — Neural Theft ile takım okundu:** 1v3 post-plant, Cypher KAY/O'yu önce öldürdü, Neural Theft ile ölü bedeni reveal etti. İkinci ve üçüncü oyuncunun Garage + A Link'te pozisyon aldığı açıldı, Cypher wire'ı A Link'e yeniden kurdu, cam'i Garage'a rotate etti, 1v3'ü 1v1'e indirdi ve round kazandı. Flip Cypher lehine — Neural Theft round içi info üretmese de round sonunda impact üretebilen post-mortem silah, pro seviye ult timing clutch round'lara çevirir.

## 7. Pro Coach Notları

Pro Cypher variation + wire reserve'e, pro KAY/O knife açı kütüphanesi + ult timing'e bağlı. Knife miss atarsa Cypher, pattern tekrar ederse KAY/O kazanır.

**Rank:** Gold-Plat: Cypher meta lokasyonlara kurar, KAY/O açı bilmez — coach variation + knife map çalışması. Diamond-Asc: KAY/O açı kütüphanesi var, Cypher reserve yok — coach wire bölmeyi + knife-ult senkronunu işler. Immortal+: variation + counter-variation, pattern savaşı.

**VCT:** FNC Chronicle Cypher pick'i KAY/O counter comp'larına variation ile direniyor. LEV Aspas KAY/O Americas'ta knife açı kütüphanesi ile dominant. NRG s0m/FNS utility zone'unu knife radius'una göre planlıyor. T1 xccurate KAY/O Pacific'te Null Cmd timing ile değer üretiyor. Meta: Cypher A, KAY/O A; head-to-head KAY/O hafif avantajlı, pro variation dengeler.
