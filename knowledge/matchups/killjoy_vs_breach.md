# MATCHUP: Killjoy vs Breach

## 1. Matchup Özü

Killjoy turret + alarmbot + nanoswarm setup'ıyla Breach'in fault line + flash + aftershock wall-pierce zincirine karşı site anchor'layan sentinel, Breach ise stun + damage area CC ile Killjoy'un utility hattını cover arkasında bile siler. Matchup Killjoy'un setup katmanı ile Breach'in wall-pierce baskısını test eder.

## 2. Kim Avantajlı?

**Killjoy lehine durumlar:**
- Close-range site anchor'da (Bind Hookah, Sunset B) — turret dar choke'ta Breach entry'sini tag'ler
- Breach utility harcanmış — stun + flash yok, Killjoy setup serbest
- Killjoy Lockdown ult Breach push penceresinde — detain area Breach'i stun lineup'tan keser
- Uzun mesafeli duellolarda — Breach utility range sınırlı, Killjoy turret uzun koridoru tarar

**Breach lehine durumlar:**
- Fault line stun Killjoy anchor pozisyonunu wall-pierce ile yakaladığında — cover'da bile stun geçer, turret reaktive edemez
- Aftershock Killjoy utility hattında — wall-pierce damage turret + alarmbot HP'sini düşürür
- Breach flash Killjoy peek hattında — aim duel bozulur, setup defend'i kaybolur
- Rolling Thunder ult Killjoy anchor'a — area stun wall-pierce, Killjoy cover'da bile iptal

**Balanced:** Haven, Ascent, Lotus gibi orta mesafeli map'lerde matchup Breach'in stun lineup disiplini ile Killjoy setup varyasyonuna bağlı.

## 3. Key Düellolar

**IF** Breach fault line Killjoy anchor pozisyonunu wall-pierce stun'ladı
**MEANING** Killjoy cover'da bile stun geçer, turret aktive edemez, reaksiyon penceresi yok
**COUNTER** Killjoy anchor pozisyonunu fault line lineup hattı dışına. Fault line ses indicator stun cancel sinyali, hızlı reposition.
**WHY** Fault line wall-pierce area stun. Sabit anchor pozisyonu fault line için bedava hedef. Varyasyon fault line'ı boşa çıkarır.

---

**IF** Breach aftershock Killjoy turret + alarmbot hattına atıldı
**MEANING** Aftershock wall-pierce damage utility HP'sini düşürür, turret damage tamponunu aşan aftershock hit'i yiyor
**COUNTER** Killjoy turret + alarmbot yerleşimini aftershock lineup dışı noktalara. Aftershock sabit lineup, bypass öğrenilir.
**WHY** Aftershock area + wall-pierce damage. Utility cover'da saklanmak korumaz — lineup bilgisi matchup'ın cevabı.

---

**IF** Killjoy Lockdown ultunu Breach push penceresine attı
**MEANING** Lockdown area detain Breach'i radius içinde dondurur, Breach utility kullanamaz
**COUNTER** Breach Lockdown sesine reaksiyon radius dışına, fault line stun Lockdown kurulum penceresinde reaktif atış.
**WHY** Lockdown push iptal silahı. Breach'in stun zinciri area-based — Lockdown area'da Breach utility'si boşa.

---

**IF** Breach Rolling Thunder ultunu Killjoy setup hattına attı
**MEANING** Area stun wall-pierce Killjoy'u cover arkasında bile yakalar, ult süresince utility defend iptal
**COUNTER** Killjoy Rolling Thunder ses indicator radius dışına, dik açıda reposition. Ult directional, yön dışı alan güvenli.
**WHY** Rolling Thunder sabit yön area stun. Dik açı reposition ult hat'ı dışına çıkış.

---

**IF** Killjoy turret Breach entry hattında, Breach fault line turret lineup'ında
**MEANING** Iki utility aynı hatta çakışır — turret tag + fault line stun aynı anda aktive olur
**COUNTER** Breach fault line'ı turret sight dışı corner'dan atar, turret reaktive olamaz. Killjoy turret'i fault line lineup dışı.
**WHY** Timing savaşı. Fault line atış hızlı, turret reaksiyon hızlı — kim önce aktive olursa matchup avantajı onda.

---

**IF** Killjoy nanoswarm Breach'in fault line lineup pozisyonunda
**MEANING** Fault line atıldığında Breach pozisyonu sabit, nanoswarm area damage Breach'i lineup anında bitirir
**COUNTER** Breach fault line lineup'ını nanoswarm lineup dışı noktalara. Round 1 nanoswarm harcatmak için alternatif lineup.
**WHY** Nanoswarm area damage. Breach fault line pozisyonu statik — statik hedef nanoswarm için bedava.

---

**IF** Breach flash Killjoy peek hattında
**MEANING** Flash Killjoy aim'ini kör eder, turret tag reaksiyonu var ama Killjoy kendisi aim'siz
**COUNTER** Killjoy flash sesine reaksiyon cover'a çekil, turret flash'tan etkilenmez. Turret reaktif tag Breach follow-up'ı yakalar.
**WHY** Turret aim'i flash'tan bağımsız. Killjoy kendi aim'ini kaybetse bile turret defend çalışır.

## 4. Utility Takası

Killjoy ekonomisi turret + alarmbot + nanoswarm x2 + ult (setup + area detain), Breach ekonomisi fault line + flash + aftershock + ult (stun + blind + damage + area stun). İki agent da utility-heavy. Breach wall-pierce ile Killjoy cover disiplinini aşar, Killjoy turret reaktive damage ile Breach push penceresini kapatır. Matchup asimetrik: Breach cover'ı aşar, Killjoy area detain ile Breach push'u iptal eder. Ult ekonomi: Lockdown 8 point, Rolling Thunder 9 point — Breach ult pahalı.

## 5. Map Bazlı Değişim

**Split (Breach hafif avantajlı):** Dar koridorlar fault line meta, Killjoy B Site anchor.

**Bind (Killjoy avantajlı):** Close range setup Killjoy meta.

**Sunset (Breach hafif avantajlı):** Dar choke Breach stun meta.

**Ascent (Balanced):** Killjoy A/B anchor, Breach A Main entry.

**Haven (Balanced):** Killjoy B anchor, Breach B Main stun.

**Icebox (Killjoy avantajlı):** Uzun sightline Breach range dışı.

**Lotus (Balanced):** 3 site yapısı iki agent için nötr.

## 6. Flip Moment'ler

**Flip 1 — Fault line anchor stun:** Killjoy cover'da bile stun, defend penceresi kayıp.

**Flip 2 — Nanoswarm Breach lineup yakaladı:** Breach lineup pozisyonunda nanoswarm area damage ile biter.

**Flip 3 — Lockdown Breach push iptal:** Ult süresince Breach utility'siz.

**Flip 4 — Rolling Thunder setup cover aşımı:** Killjoy anchor ult stun altında.
